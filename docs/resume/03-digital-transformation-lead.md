## 一句话

我做过生产、供应链和物流，不是只懂 IT 的人；我能把业务问题翻译成系统需求，推动 APS、LMS/LogiX、条码/Andon 上线，再用流程、数据和使用率验收。2024 年起在跨境电商从 0 到 1 推物流系统，知道系统失败往往不是功能不够，而是责任、数据和习惯没有一起改。

1. **LMS/LogiX 物流系统 0→1（2024–至今）**
   端到端流程梳理 → IT 需求翻译 → 业务表单配置 → 系统对接 → 全员培训；同步建快递费用标准库、渠道结构/附加费/服务商价差拆解和报价系数工具。

3. **BPM 与数据化（宁波萌恒，2015–2024）**
   BPM 三层级流程体系；数据化/可视化让进度、结果、异常透明；知识管理把一线方法沉淀。流程、数据、系统、培训四条线一起推进。

4. **自主设计与开发流程管理系统（个人项目）**
   流程架构、流程资产包、证据账本、日志前后对照、阶段门；前端 ES 模块 + FastAPI + SQLAlchemy + PostgreSQL。用于验证“流程—证据—系统”闭环，不作为已商用产品宣称。

## 为什么匹配数字化转型

- **业务出身**：生产、供应链、物流都做过，知道系统要解决的是交付、成本、库存，不是一个漂亮看板。
- **能翻译需求**：能把“部门抱怨”拆成流程问题、数据问题、系统问题；能判断买、配、改、自研的边界。
- **能推落地**：做过选型、配置、接口、培训、上线；关注使用率、线上化率、处理时长、差错和费用。
- **能自己动手**：SQL、Python、Excel 建模、低代码、API、BI；必要时能搭原型验证，不空谈方案。

## 到岗后先做什么

- **0–30 天**：盘点现有系统、数据、接口和使用率；找出“上线了但没人用”的原因。
- **30–60 天**：选一条端到端流程做样板，把流程、数据、系统、培训一起打通；建立指标基线。
- **60–90 天**：用样板证明业务结果，再复制；建立系统变更、数据口径和权限规则。
