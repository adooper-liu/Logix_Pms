## 我能解决什么问题

不是只交一份流程报告，而是把问题从现场带到流程、系统和经营结果：

1. **流程乱、责任不清**：梳理端到端流程，明确 L1–L3 边界、节点责任、RACI、控制点与表单。
2. **有流程没系统**：把业务需求翻译成系统方案，推动 APS、LMS、条码/Andon 等落地。
3. **有系统没人用**：从责任、数据、习惯和培训一起改，不把“上线”当完成。
4. **改善算不清账**：先定基线，再看周期、成本、交付、库存、差错的前后对比。

## 代表案例

### 案例 1：纺织制造 · 端到端流程再造 + APS

- 背景：500+ 人、年销售额 3 亿+ 的绣花制造企业，三条产线，计划靠经验，交期与在制品不稳定。
- 动作：2017 年按价值流/业务流/操作流三层梳理流程；2018 年推动 APS 系统排程；用责任、节点、表单固定执行。
- 结果：【待补：交期达成率、排程准确率、库存周转、换产次数】。
- 可复用做法：先定流程边界与责任，再上系统；先跑一条价值流，再复制。

### 案例 2：跨境电商 · 物流系统 0→1

- 背景：物流核心流程依赖线下与人工，费用口径分散。
- 动作：端到端流程梳理 → IT 需求翻译 → 业务表单配置 → 系统对接 → 全员培训；同步建快递费用标准库与报价系数工具。
- 结果：覆盖【待补：国家/仓/流程/用户】；处理时长【待补】→【待补】；降本【待补】。
- 可复用做法：流程、数据、系统、培训四条线一起推进。

### 案例 3：制造现场 · 精益与产线筹建

- 背景：儿童餐椅新产线从 0 筹建。
- 动作：选址、布局、设备调试、打样试产、工艺与质量标准、人员培训；推行精益与 ISO。
- 结果：日产量 150→450 台/天；年产值从千万增至1亿+；员工 80→300 人；人均产值 13 万→50 万；包装优化使单柜利润 +20–30%。
- 可复用做法：先解决瓶颈与物料配套，再谈自动化和系统。

### 案例 4：供应链 · 供应商集成

- 背景：自制/外购边界不清，供应商只压价不协同。
- 动作：按环节能力选择“环节冠军”；帮供应商优化流程、共享需求预测、一起降本。
- 结果：2002 年 3 个月开发 4 家外包供应商，月出 3 个 40 尺柜以上，年产值 1000 万+。
- 可复用做法：不追求全能工厂，做系统集成商。

## 合作方式

| 方式 | 适合 | 交付 |
|---|---|---|
| 流程诊断（2–4 周） | 流程乱、责任不清、系统需求说不清 | 现状流程、问题清单、优先级、目标流程草案、落地路线 |
| 项目制（2–6 个月） | 一条端到端流程或一个系统上线 | 流程设计、表单/规则建议、系统需求、试点、培训、验收指标 |
| 长期顾问（按月） | 需要持续建体系、带团队 | 月度诊断、评审、关键项目辅导、内部骨干培养 |
| 系统 + 辅导 | 想把流程、证据、门禁一起落地 | 流程管理系统试用 + 关键流程带教 |
