# 自我推介 | 流程总监 / 流程管理科负责人

应征：流程总监 · 流程管理科负责人 · 流程与运营负责人 | 宁波 | 全职

## 一句话

我不是只画流程图的顾问。我在制造企业做过 12 年 8 个月的生产运营与供应链总监，2015 年起按价值流、业务流、操作流三层做 BPM，2013 年推动 APS 上线，2024 年起在跨境电商从 0 到 1 推物流系统。流程在我这里要落到责任、表单、系统和使用者，最后回到周期、成本、交付。

## 三个可核对的经历

1. **BPM 流程再造（宁波萌恒，2015 起）**
   基于客户、员工、股东、供应商四个满意度，梳理销售→产品→生产→客户的端到端流程；分价值流、业务流、操作流三层；推进方式是先僵化、再优化、后固化；用工具和表单把关键要素、节点、操作要点标准化。

2. **流程到系统（APS / LMS）**
   2013 年推动 APS 计划系统，把经验排产改为系统排产，覆盖三条产线；2024 年起推动 LMS/LogiX 物流系统 0→1：流程梳理、IT 需求翻译、业务表单配置、系统对接、全员培训。

3. **跨行业迁移**
   五金制造 → 家纺/服装 → 纺织工贸一体 → 跨境电商。行业变了，做法没变：先统一流程语言，再定责任和节点，再上系统，再用数据验收。

## 为什么匹配流程总监

- **能建体系**：L1–L3 流程分级、RACI、控制点、退出门与证据；知道流程治理不是写文件，是让责任和例外可查。
- **能落系统**：做过生产、供应链、物流系统；能把业务语言翻译成 IT 需求，不把“系统上线”当终点。
- **能跨部门**：管过生产、供应链、计划、仓储、物流；知道部门墙背后是目标、口径和利益，不是简单的“沟通问题”。
- **能算账**：会计背景，能用成本、库存、周期、交付判断流程改善是否真的有效。

## 到岗后先做什么

- **0–30 天**：盘点现有流程、制度、系统与指标，找出“流程写了但没人执行”和“系统上了但没人用”的断点。
- **30–60 天**：选一条端到端流程做样板，统一边界、责任、节点、表单和指标；建立流程变更与评审规则。
- **60–90 天**：把样板复制到第二条流程；建立流程 Owner、RACI、退出门和证据要求；用一次真实改善证明体系有效。
