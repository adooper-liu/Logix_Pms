## 四层能力，一层层从现场长出来

### 1. 懂财务｜算得清账——看清哪里赚钱、哪里烧钱

### 2. 懂业务｜摸得清底——知道一线怎么转、钱花在哪

- **供应链与供应商**：供应链体系搭建与全盘管理，覆盖采购、寻源、供应商开发、交期、成本、品质与库存周转全链路。

### 3. 懂流程｜砍得掉浪费——端到端消除不增值环节

- **体系与标准化**：BPM 价值流、业务流、操作流三层；明确 RACI、控制点、表单与操作要点，按“先僵化、再优化、后固化”推进。
- **方法与实践**：精益 → ISO → APS → BPM → APQC；结合 IE 工程、APS 排程落地与 BPM 流程再造，把现场经验固化为可执行的体系。

### 4. 懂 IT｜落得了地——自己能动手搭系统出结果

- **业务系统**：APS、LMS/LogiX、条码/Andon；能把业务需求翻译成系统方案。
- **数据与开发工具**：Web、SQL、Python、飞书低代码、Excel 建模、API、BI 看板。

既看得懂车间，也写得了方案，还搭得起原型；不是站在旁边提需求，而是能自己把想法变成系统、让数据支撑经营结果。

## 职业路径：两条线同时长

**一条线往深走——能力跃迁。** 从现场摸到流程，从流程摸到系统，从系统摸到算账，每一步都建立在前一步的现场经验上。
**一条线往宽走——行业跃迁。** 从五金到家纺、纺织工贸一体，再到跨境电商，行业变了，底色始终没变：精益生产 × 供应链管理 × 财务思维。快速上手，靠的是从现场长出来、能迁移的方法论。

| 步骤 | 逻辑       | 做法                                                             |
| ---- | ---------- | ---------------------------------------------------------------- |
| 分类 | 算账逻辑   | 先做自制 / 外购决策：哪些环节自己干是浪费，哪些找供应商更专业    |
