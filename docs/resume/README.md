## 使用规则

1. **投递时附主简历 + 对应岗位的一份自我推介**，不要六份一起发。
2. **自我推介不重复完整工作经历**；只写 3 个硬结果、3–4 条匹配理由、到岗后 30/60/90 天。
3. **萌恒及之前的工作经历只在主简历里完整保留**；自我推介用一句话指向主简历。
4. **不写“我也能做另外几个岗位”**；自我推介只对准一个岗位。
5. 所有【待补】必须在投递前填掉；填不出来的，删掉整句，不要保留形容词。
