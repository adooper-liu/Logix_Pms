# 界面进入、跳转与退回路径

> 结构基准已收敛到 [企业管理体系图谱](enterprise-management-system-atlas.md)；
> 本文保留页面级进入、跳转与退回契约。
>
> 目标：用户在任何页面都能回答三个问题：
> **我从哪里来、我现在在哪、我要回到哪里。**
>
> 本文是导航契约。新增页面或新增跨页跳转时，必须按这里的规则接线；
> 不要在每个视图里另造一套返回按钮。

---

## 1. 固定主入口与主路径

**唯一主入口：`工作台`（`workbench`）。**

- 登录后默认落地 `workbench`，不再根据试点进度切到驾驶舱；
- `workbench` 只回答「今天先做哪件事」，三个起点：

```text
从流程框架开始  → 建 L1/L2/L3，或打开流程框架
从一个流程开始  → 选 L3，进入流程资产工作台
从一个项目开始  → 新建/打开改善项目
```

- 顶部常驻「⌂ 工作台」按钮，任何页面一点即回 `workbench`；
- 侧栏「工作台」与「主线」按钮等价，都是顶层入口；
- 其他页面都是**模块视图**，不是第二入口。它们从工作台进入，完成后回工作台；
- `体系总览 start` 保留为参考页/深链，不再占主导航，也不作为默认落地。

---

## 2. 三层导航语义

| 层级 | 行为 | 是否记入来源栈 |
|---|---|---|
| 侧栏 / 主线按钮 | 顶层切换，清空来源栈 | 否 |
| 跨页面内容跳转 | 记录来源，目标页显示「← 返回 来源页」 | 是 |
| 同页面参数切换（筛选、下拉、页签） | 只更新 URL/状态，不记来源 | 否 |
| 弹窗内跳转 | 先关闭/压栈弹窗，再按跨页面跳转处理 | 是（记录页面） |
| 浏览器后退/前进 | 走 URL 历史，清空应用来源栈 | 否 |

来源栈最多保留 10 层。连续 A→B→C 时，C 的「返回来源」回 B；回到 B 后仍可继续回 A。

| 流程卡 | 打开设计器 | 流程设计器 `designer?process=id` | 返回 流程卡 |
| 流程卡 | 战略目标 / 运营监控 / 项目组合 / 标准文件 | 对应模块 | 返回 流程卡 |

| 流程设计器 | 去流程执行 | 流程执行配置页 | 返回 流程设计器 |
| 工具箱 | 在知识库查看 | 流程知识库 `knowledge?tool=code` | 返回 方法论工具箱 |

## 5. 退回路径

### 5.1 返回来源页（推荐）

- 任何**跨页面内容跳转**都会记录来源；
- 目标页顶部出现「← 返回 来源页」，例如「← 返回 流程卡」；
- 返回时保留来源页的 URL 上下文（`project`、`process`、`stage`、`tab` 等）；
- 连续跳转按来源栈逐层回退；
- 侧栏切换或点「主线：0→1」会清空来源栈。

### 5.2 浏览器后退 / 前进

- 与来源栈并存，但浏览器历史导航会清空应用来源栈；
- 刷新后来源栈不保留，只保留当前 URL 上下文。

### 5.3 弹窗

- 弹窗内关闭（Esc / ✕ / 关闭）回到**上一层弹窗**，由弹窗栈保证；
- 弹窗内跳转到其他页面时，页面级来源条负责回到来源页；
- 跨页返回不会自动重新打开原弹窗；需要继续处理时从页面重新进入。

### 5.4 主线

- 顶部「⌂ 工作台」常驻；
- 点击后回到 `workbench`，并清空来源栈；
- 这是用户迷路时的唯一兜底入口。

## 6. 上下文参数

来源栈保存的是跳转前的 **view + URL 参数**，因此以下上下文会自动保留：

```text
process  流程 id / code
project  项目 id
stage    阶段号
tab      页签
path     试点路径 id
layer    十层号
step     标准步骤号
open     工具编码
```

新增页面时，把可分享/可恢复的筛选条件写进 URL（`setUrlState` / `go(params)`），
不要只存在 `state` 里，否则「返回来源」无法恢复。

---

## 7. 新增页面/跳转的检查清单

- [ ] 页面能从侧栏或主线进入；
- [ ] 页面有明确的 `TITLES` 中文名；
- [ ] 跨页跳转用 `go(view, { params, push: true })`，不要手动改 `location.hash`；
- [ ] 可分享的上下文写进 URL；
- [ ] 从本页跳到别页后，目标页能显示「返回 来源页」；
- [ ] 弹窗内跳转先 `closeModal()`，再 `go()`；
- [ ] 不新增第二套返回按钮或第二套主入口；
- [ ] 在 `scripts/verify_frontend.py` 里补一条进入/返回检查。

---

## 8. 当前已知边界

- 返回来源恢复的是**页面和 URL 上下文**，不恢复弹窗打开状态、滚动位置和未提交草稿；
- 来源栈只在当前浏览器会话内有效，刷新后清空；
- 侧栏是顶层切换，不进入来源栈；如果希望从模块回侧栏上一页，用浏览器后退。
