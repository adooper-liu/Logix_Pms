# 简历能力 → 系统支持力对照

本文用于内部演示与面试讲解：把简历里的能力主张映射到 Logix PMS 里可点击、可验证的入口，并明确系统边界，避免把“流程治理系统”说成 ERP/MES/WMS/APS/财务系统。

## 一句话定位

Logix PMS 是**流程治理与改善系统**：统一流程语言、把改善做成项目、用退出门和证据链保证方法论落地，并让流程、RACI、KPI、标准工时、知识方法、交付物在同一套体系里可追溯。

业务交易在 ERP / MES / WMS / APS / 财务系统里；本系统回答的是：

> 流程怎么设计、谁负责、凭什么放行、改善有没有证据。

## 五分钟演示路径

1. **能力地图**：先看四层能力 × 五大收益，建立全局。
2. **企业流程地图 → PCF**：统一语言，看 L1–L4 与 APQC 映射。
3. **战略目标 → 流程项目组合**：目标承接、立项、KPI 基线/目标。
4. **五阶段工作台**：阶段1战略 KPI 承接 → 阶段2根因证据（绑定根因门、独立裁决）→ 退出门。
5. **流程设计器**：建模 → PCE/等待/返工/移交/瓶颈测算 → 方法论建议 → 版本/变更。
6. **流程执行**：实例/任务/认领/完成/SLA/升级/过程挖掘。
7. **运营驾驶舱**：红黄 KPI/异常 → 一键转改善项目。
8. **方法论工具箱**：按问题/场景/阶段/步骤匹配工具，看使用证据与复核。
9. **十层单页 / 复制资产包**：从试点到复制。

## 明确不支持（不要在面试中声称）

- 供应商 / 采购 / 库存 / 仓储 / 物流 / 运单 / 承运商 / 运费 / 预提 / 报关 / EUDR
- APS 有限产能排程
- WMS / 条码 / Andon / 立体仓
- 财务核算：总账、成本核算、杜邦、本量利、标准成本差异、边际贡献
- 飞书低代码（本系统是自研 FastAPI + 原生 ES 模块）
- 历史业绩数字本身（预提准确率 95.3%、月结 3→1 天、日产量 150→450、单柜利润 +20–30% 等）——它们是过去的经营结果，系统负责记录为项目/KPI/证据，不负责自动复现

## 面试话术

> 我做的是流程治理与改善系统，不是 ERP/MES/WMS。业务交易在那些系统里；我把 APQC 统一语言、五阶段改善、退出门、证据链、RACI、KPI、标准工时和知识方法串成一条可执行、可审计的链路。这个系统能证明的是：我不仅会讲方法论，还能把方法论变成强制执行的系统和证据。
