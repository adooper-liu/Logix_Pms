# 简历能力 → 系统能演示什么

简历正文见 [resume.md](resume.md)。本文给内部演示和面试用，只写当前代码里点得开、数得着的东西。系统没有单独的「能力地图」页，讲解从侧栏和「开始使用」走。

侧栏按页面真正读写的数分成两组：

- **把公司这套办法建起来**：开始使用、十层单页、组织与人员、企业流程地图、授权矩阵
- **把一条流程改好**：战略目标、流程项目组合、流程设计器、流程执行、运营驾驶舱

五阶段工作流、流程卡、方法论工具箱、交付物、PCF、架构草图、数据治理不在侧栏里。它们从对应步骤或页面里打开。

## 一句话

Logix PMS 管的是流程怎么设计、谁负责、凭什么放行、改善有没有证据。

业务交易在 ERP、MES、WMS、APS 和财务系统里。这里不建那些对象。

## 两套钟，不要叠在一次点击里

**开始使用**是公司这套办法建到哪了。一共 9 个阶段，当前位置是第一个还没就绪、也没有跳过的阶段。点别的阶段只是查看它的证据，不改当前位置。前 8 个阶段都就绪，才算首次上线；跳过不算就绪。第 9 阶段「改善与复制」不挡住首次上线。

这一页上的数字是**全公司计数**。阶段 2 的四项（有目标、已挂到流程、有责任人和目标值、有现状基线）可以来自四条不同的目标。阶段 1 的「L3 已绑定负责人」数的是每一条已经绑了负责人账号的 L3（`owner_user_id`），不是地图上显示的负责人文字，也不是「只选了一条试点」。数字本身可以点，打开的就是这批记录。

**流程项目**是改一条流程。它用五阶段。阶段 1 退出要先关联流程，并至少挂上 2 项有效战略 KPI。阶段 2 的根因门只认已经绑到这道门上的证据：同一主张至少两类，并且由非创建人裁决为支持。这套门不替代开始使用的全公司计数。

十层单页是某一条 L3/L4 的核对单。层的退出条件复用开始使用的证据，不另判一套。新建一条路径不会自动造出证据，也不会推动公司阶段。

## 演示时从哪进

| 要讲的事 | 从哪进 | 点开后看到什么 |
|---|---|---|
| 公司建到哪一步 | 开始使用 | 9 个阶段；当前阶段的证据数字可点 |
| 哪些 L3 绑了负责人账号 | 开始使用 →「L3 已绑定负责人」 | 企业流程地图只列出这些 L3 |
| 谁对结果负责 | 开始使用 →「治理角色」 | 组织与人员的治理角色页 |
| 目标、基线、挂到哪条流程 | 战略目标 | 目标列表 |
| 改一条流程的阶段门 | 流程项目组合 → 打开项目 | 五阶段、证据、退出门 |
| 统一分类语言 | 企业流程地图，打开对标 | L1–L4 与 APQC 的对应 |
| 谁执行、谁负责 | 流程设计器 → 权责 | RACI；授权规则在授权矩阵，两处不是同一页 |
| 标准工时、当月产能 | 运营驾驶舱 → 工作量 | 标准工时卡、产能 |
| 红黄 KPI | 运营驾驶舱 → KPI | KPI 卡和数据点；红黄可转改善项目 |
| 周期、等待、返工、移交 | 流程设计器 → 分析 | PCE、瓶颈节点、方法论建议 |
| 表单和规则 | 流程执行 → 配置 | 表单与规则 |
| 制度、模板、治理待办 | 从阶段 4 或阶段 9 的按钮进入交付物 | 标准文件；待办在基线页 |
| 方法和案例 | 从项目步骤进入方法论工具箱 | 按问题、场景、阶段、步骤匹配 |
| 一条流程的十层核对 | 十层单页 | 路径上的十层，门用开始使用的证据 |
| 成熟度 | 流程卡 | 该流程的成熟度记录；侧栏没有单独的成熟度页 |

算账能记在项目上的字段是预算、实际成本、一次性投入、转移成本、收益说明、ROI 估计，以及 KPI 的基线、目标、当前值。设计器分析给出 PCE、单位执行成本和可释放人天。没有杜邦、本量利、标准成本差异、边际贡献这些模型。

## 不要说成系统做出来的

- 供应商、采购、库存、仓储、物流、运单、承运商、运费、预提、报关、EUDR
- APS 有限产能排程
- WMS、条码、Andon、立体仓
- 总账、成本核算、杜邦、本量利、标准成本差异、边际贡献
- 飞书低代码。本系统是自研 FastAPI 加原生前端
- 预提准确率、月结天数、日产量、单柜利润这些历史经营数字。系统只能把它们记成项目、KPI 或证据，不会自己复现当年的结果

## 讲解时可以怎么说

我做的是流程治理和改善系统。业务交易在 ERP、MES、WMS 里。我把统一的流程语言、九阶段把公司办法建起来、五阶段把一条流程改完、退出门、证据、RACI、KPI、标准工时和工具方法串成一条能点开、能核对的链路。系统证明的是方法论有强制的起点和证据，不是我做过那些业务交易。
