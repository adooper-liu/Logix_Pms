# 框架 P2 项目：预测、能力与过程挖掘

> 来源：`docs/framework-gap-analysis.md` 的 P2 清单。独立项目推进。

## 范围

| 阶段 | 交付物 | 状态 |
|---|---|---|
| F1 工作量预测与派工均衡 | 基于已验证标准工时和产能的前瞻预测、缺口与调拨建议 | ✅ 2026-10-25 |
| F2 过程挖掘 | 从执行事件还原路径变体、频次、耗时与偏离 | ✅ 2026-10-25 |
| F3 能力矩阵与岗位匹配 | 技能字典、岗位要求、人员技能与匹配度 | 后续 |
| F4 绩效与激励联动 | 需要绩效周期与激励规则的业务口径 | 后续 |
| F5 并行网关 what-if | 依赖 BPMN 多令牌引擎 | 与 BPMN B5 合并评审 |

## 明确不做

- 不使用抽样数据冒充全量：预测只基于已验证标准工时与已登记产能。
- 不在过程挖掘里推断因果，只呈现路径与偏离事实。
- 不把技能矩阵做成第二套组织主数据；人员与岗位仍以现有主数据为准。

## 验收

- 预测与均衡建议可解释（给出岗位、缺口、可调拨来源）；
- 过程挖掘按流程和时间窗筛选，输出 Top 变体与偏离节点；
- 独立提交并通过后端测试与前端自检。
