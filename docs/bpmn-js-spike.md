# bpmn-js 技术验证（Spike）

> 结论：**采用 bpmn-js 作为默认专业 BPMN 画布**，停止继续扩展自研画布。
> 「简洁画布」暂时保留为降级/对照模式，后续删除。

## 1. 选型

| 项目 | 结果 |
| --- | --- |
| 组件 | bpmn-js 18.31.1 |
| 来源 | npm registry 预构建包 |
| 许可证 | MIT 风格；**要求保留 bpmn.io 水印** |
| 本地路径 | `web/vendor/bpmn-js/` |
| 引入方式 | 原生 `<script>` + CSS/字体，懒加载，无构建步骤 |

选择原因：它是 Camunda Modeler 的底层编辑器，原生支持调色板、连线折点、上下文菜单、
撤销/重做、复制粘贴、快捷键、缩放、泳道和完整 BPMN 2.0 元素；相比自研画布，
编辑能力是数量级提升，且可以直接本地托管。

## 2. 已验证内容

- 在流程设计器中加载 L3-032，渲染出 5 条泳道、20 个图元素。
- 调色板、上下文菜单、节点选中、双击改名可用。
- 画布高度随视口自适应（`clamp(640px, 100vh - 230px, 980px)`），并提供「适应画布」。
- 支持全屏画布（Esc 退出）；全屏切换后自动 `canvas.resized()` + 适应视口。
- 内置 bpmnlint（recommended 规则，去掉会误报的 no-bpmndi），问题可点击定位到元素；
  规则名和英文消息在前端翻译为「问题 + 影响 + 建议」，原始规则保留在悬停提示里。
- 内置 bpmn-auto-layout，一键重新排列并保存；布局/折点写入 BPMN XML。
- **自动布局保留泳道**：bpmn-auto-layout 只排 `flowElements`，前端在结果上补回泳道 DI，
  保留它的横向顺序、按泳道重排纵向区域，并同步修正连线折点。
- **调色板/上下文菜单/「更改元素」菜单过滤执行引擎不支持的构造**：子流程、边界事件、
  并行/复杂/事件网关、事务子流程不再出现；等待事件改为直接创建中间捕获事件。
- 选中元素后，下方属性区可直接编辑 PMS 指标（作业/等待/成本/返工/审批层级/增值）。
- 选中活动节点后，同一属性区可直接维护节点分派与 SLA（候选角色/组织/默认处理人/
  节点时限/升级时限与处理人），无需切换简洁画布或打开节点弹窗。
- 拖动节点/连线后自动保存为草稿（900ms 防抖），保存状态显示 `已保存 · v...`。
- **完整 BPMN XML（含 DI 坐标、泳道、连线折点）存储在 `process_model_version.bpmn_xml`**；
  刷新后按原样恢复，不再重新生成布局。
- 保存走 `POST /processes/{id}/bpmn`，只更新草稿，不影响运行时模型。
- bpmn-js 保存后，后端按节点 id/连线起止合并 PMS 字段，指标不会被清零。
- PMS 指标通过 `PATCH /processes/{id}/design/nodes/{node_key}` 单独保存，保留 BPMN 版面。
- 导出 BPMN 时先保存当前画布，再由后端把最新 PMS 字段同步进 XML 后导出。
- bpmn.io 水印保持可见，符合许可证要求。
- Playwright 自检覆盖：加载画布、调色板过滤、元素数量、水印、更换元素菜单、
  自动布局保留泳道、切回简洁画布。

## 3. 当前边界

- **自动布局**：bpmn-js 忠实保留 BPMN DI 坐标；需要重排时使用「自动布局」
  （bpmn-auto-layout），导入的复杂模型也可一键整理。自动布局结果会补回泳道 DI。
- **执行不支持的构造**：bpmn-js 可以画并行网关、子流程、边界事件，但执行引擎暂不支持；
  这些入口已从调色板、上下文菜单和「更改元素」菜单移除。从外部导入包含这些构造的
  文件时，后端保存仍会拒绝并给出提示。
- **简洁画布**：仍保留为降级/对照模式；bpmn-js 已默认启用。
- **版本治理**：bpmn-js 保存只写草稿；评审/发布/回滚继续走现有版本治理链路。
- **draw.io**：作为独立的「架构草图」白板存在，不替代 bpmn-js，详见
  [sketches.md](sketches.md)。

## 4. 下一步

1. 删除自研画布中与 bpmn-js 重复的编辑逻辑，避免两套实现。
2. 增加协作编辑/评论与模板库。
