# L3-032 Gate 4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Checkboxes track executed work, not business approval.

**Goal:** 完成用户已限定的 Gate 4 规范配置补齐，不代造业务批准、真实运行或 Gate 5 责任事实。

**Architecture:** 复用原模型版本、NodeActivityLink、FormDefinition、ActivityResourceLink 和流程标准文件，不建平行台账。保留 V1 与全部历史版本，从已发布模型追加干净工作版；配置内容及未确认项写入原流程文件草稿。条件分支不可被显式下一节点或单出边兜底绕过。

**Tech Stack:** Python / SQLAlchemy / PostgreSQL；pytest 隔离 SQLite。

**Spec:** docs/superpowers/specs/2026-11-13-l3-032-process-acceptance-baseline.md（Gate 4，第 275–318 行），以及本次用户明确的五项范围。

## Global Constraints

- 不发布模型、不写业务批准、不生成业务实例、不推进 Gate 5。
- 不改历史实例、历史版本、岗位/RACI/账号分派。
- 配置仅 E1，实际预算、审批、签收及运行仍待真实业务证据。
- 不新增 schema、不迁移经营周期表、不新增前端页面。
- 工作版保留 DRAFT 并冻结绑定依据；缺口文件保留 DRAFT。
- 无来源的时限、日历、升级责任和异常补偿只记缺口，不编数字或责任人。

## Review Focus

- 重复运行不得重复建版本、资源或文件，也不得覆盖人工后改内容。
- 最新草稿含未连接测试节点，必须保留原件且不继承测试污染。
- 审批否不能显式跳到通过；有条件的单出边不得无条件落下。
- 配置补齐不应触碰既有业务实例、人员和已发布版本。
- 任一前置校验不满足须整体回滚，检查模式不得写入。
